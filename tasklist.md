# Task List

The following tasks outline the steps to build a simple photographer website using React/Vite and host it on GitHub Pages.

## 1. Scaffold Vite React Project
- Create `package.json` with dependencies.
- Add Vite config.
- Set up scripts (dev, build, preview, deploy to GitHub Pages).

## 2. Create Project Structure
- `public/index.html` with root div.
- `src/main.jsx` to render `<App />`.
- `src/App.jsx` as root component.
- `src/components/Gallery.jsx` for image gallery.
- `src/components/ContactForm.jsx` for contact form.
- `src/styles.css` for global styles (imported in `main.jsx`).

## 3. Static Assets
- Create `public/images/` directory for image uploads.

## 4. Add Styling
- Use the provided `styleguide.md` to create CSS classes.

## 5. GitHub Pages Deployment
- Add a `deploy` script using `gh-pages`.
- Configure `homepage` in `package.json`.

## 6. README
- Document installation, development, build, deploy steps.

## 7. (Optional) Contact Form
- Basic form that posts to Formspree or similar.
